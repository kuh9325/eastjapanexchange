# 충남·충북·대전 청년 활동 지도 전시

일본 청년 교류 행사에서 충남·충북·대전방면의 좌담회, 창가청년스쿨, 청년미래총회, 평상시 활동 사진을 지도와 함께 전시하는 터치 친화형 웹앱입니다.

## 디자인 결정

- **지도 범위:** 북한을 포함한 한반도 전도가 아니라 대한민국 실효 지배 구역의 실루엣을 사용합니다. 일본 방문자에게 위치 맥락은 전달하면서, 전시 대상 세 방면이 작아지는 것을 막습니다.
- **초기 화면:** 지도를 중앙의 주인공으로 보여줍니다. 방면을 선택하면 지도는 왼쪽으로 줄어들고 사진 콜라주가 오른쪽에서 나타납니다. 먼저 ‘어디인지’를 이해하고 다음에 ‘어떤 사람들이 활동하는지’를 보게 하는 흐름입니다.
- **방면 구분:** 충남, 충북, 대전은 서로 다른 색과 굵은 외곽선으로 묶고 시·군 단위 경계는 얇게 표시합니다.
- **조직상 예외:** 대전방면은 대전광역시와 세종특별자치시, 충남의 계룡·금산, 충북의 옥천을 포함합니다. 충남방면은 계룡·금산을 제외하고, 충북방면은 옥천을 제외합니다.
- **전시 초점:** 나머지 대한민국 지역은 회색 맥락으로만 표시하며, 버튼과 사진 전시는 세 방면만 활성화합니다.

> 현재 지도는 전시 전달력을 우선한 **단순화된 시·군 수준 도식 지도**입니다. 법적·행정적 경계 확인용이 아닙니다.

## 실행

Node.js 18 이상이 필요합니다.

```bash
npm run dev
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 사진 추가

자세한 방법은 [`assets/gallery/README.md`](assets/gallery/README.md)를 참고합니다.

```bash
npm run assets
```

## 배포

`main` 브랜치에 push하면 `.github/workflows/pages.yml`이 `dist`를 빌드해 GitHub Pages에 배포합니다. 저장소 Settings → Pages에서 Source를 **GitHub Actions**로 설정합니다.

## 권장 전시 환경

- 가로형 16:9 모니터 또는 터치 디스플레이
- Chrome, Edge, Safari 최신 버전
- 전체 화면 모드
- 사진은 가급적 긴 변 2000px 전후, WebP 또는 품질 80~88의 JPEG

## 접근성

키보드 Enter/Space로 지도 선택, 방향키로 확대 사진 이동, `prefers-reduced-motion` 지원, 큰 터치 영역 및 이미지 대체 텍스트를 적용했습니다.
