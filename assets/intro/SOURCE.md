# 일본·홋카이도 인트로 지도

`japan.svg`는 Natural Earth의 `ne_10m_admin_0_countries`와
`ne_10m_admin_1_states_provinces` 데이터를 전시용으로 단순화하고,
일본과 홋카이도만 추출해 만든 로컬 SVG입니다.

- 원본: Natural Earth Vector
- 사용 버전: `nvkelso/natural-earth-vector` commit `ca96624a56bd078437bca8184e78163e5039ad19`
- 라이선스: Public Domain
- 생성 목적: 실제 지형에 근거한 인트로 화면. 항법·측량용이 아닙니다.

Natural Earth는 모든 raster/vector 지도 데이터를 공개 도메인으로 제공합니다.
웹앱 실행 중에는 원본 사이트나 외부 지도 서버에 접속하지 않습니다.
