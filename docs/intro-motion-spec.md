# 인트로 모션 사양

총 길이 15초, 기준 속도 1×. 시간값은 `src/intro.js`의 `INTRO_TIMELINE`에서 관리한다. 지도 타일이나 외부 네트워크 요청 없이 로컬 SVG만 사용한다.

| 시간 | 단계 | 화면과 동작 |
|---:|---|---|
| 대기 | 환영 | 홋카이도와 일본을 대한민국보다 먼저 표시하고 `韓国へようこそ`, `出発`, `スキップ`을 제공한다. 오프닝의 관람객용 문구는 모두 일본어로 표시한다. |
| 0–1초 | 출발 | 신치토세공항 부근 출발점을 보여주고 중복 입력을 잠근다. |
| 1–3초 | 줌아웃 | 홋카이도 중심 확대 화면에서 일본 열도를 먼저 보여준 뒤 대한민국 지도를 점진적으로 표시하며 두 나라가 함께 보이는 화면으로 SVG group을 이동·축소한다. |
| 3–8초 | CTS → ICN | 점선 Bezier path를 표시한다. 로컬 여객기 실루엣 SVG가 `getPointAtLength()` 좌표와 다음 점의 각도를 이용해 이동한다. `약 1,420 km`를 표시한다. 국내 두 지점은 아직 숨긴다. |
| 8–9.5초 | 인천 도착 | 비행기를 숨기고 대한민국 쪽으로 group을 확대·이동한다. |
| 9.5–11.8초 | 인천 → 진천 | 진천 지점을 먼저 표시하고 0.5초 뒤 점멸하는 이동 점이 한국SGI 진천연수원(초평면 초평로 1048-6)으로 바로 이동한다. |
| 11.8–14초 | 진천 → 대전 | 대전 지점을 먼저 표시하고 0.5초 뒤 한국SGI 대전문화회관(대덕구 비래동로40번길 46) 도착점까지 이동한다. |
| 14–15초 | 도착/전환 | `대전 도착`을 알리고 인트로를 fade out한 뒤 메인 대한민국 지도에 포커스를 넘긴다. |

## 제어와 정리

- `건너뛰기`: 현재 `requestAnimationFrame`과 모든 timeout을 취소하고 즉시 메인 화면으로 전환한다.
- `여정 다시 보기`: scene, 버튼, ARIA 상태, transform을 초기값으로 되돌린다.
- `?intro=preview`: 종료 1.1초 뒤 반복하며 일시정지, 처음부터, 0.5×/1×/2×를 제공한다.
- `pagehide`: 남은 frame과 timer를 취소한다.
- 중복 출발: 재생 중 `running` guard와 disabled 출발 버튼으로 막는다.

## 축소 모션과 실패 fallback

`prefers-reduced-motion: reduce`이거나 rAF, `getTotalLength`, `getPointAtLength` 중 하나가 없으면 복잡한 transform 이동을 실행하지 않는다. 신치토세공항, 인천국제공항, 충북 진천, 대전을 짧게 순차 표시한 뒤 같은 메인 화면으로 전환한다. 인트로 중 오류가 발생해 앱 초기화가 실패하면 최상위 오류 처리기가 인트로를 숨기고 메인 화면을 노출한다.

## 좌표와 거리

- CTS: 42.7752, 141.6923
- ICN: 37.4602, 126.4407
- 지구 반지름: 6,371km
- Haversine 대권거리 계산 후 10km 단위 반올림: 약 1,420km

지점은 `data/intro-route.js`에서 원본 로컬 SVG 좌표로 정의하고 장면 좌표로 변환한다. CTS는 Natural Earth 일본 SVG의 신치토세공항 위치, ICN은 SGIS 대한민국 지도의 영종도 공항 위치를 사용한다. 진천·대전은 위 시설 주소가 속한 시군구 도형 안의 위치에 고정한다. 지점 사이의 이동선은 전시 서사를 위한 도식이며 도로 안내나 항법을 위한 정밀 경로가 아니다.

## 성능 기준

transform, opacity, SVG attribute 갱신만 매 frame 수행한다. `setRuntimeStatus`와 접근성 단계명은 단계가 바뀔 때만 갱신하고, 무거운 blur/filter나 CSS motion path를 사용하지 않는다. 목표는 STS-75IR11 Opera에서 30fps 이상이며 가능한 경우 60fps이다.
